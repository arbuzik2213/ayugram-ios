# AyuGram для iOS (Flutter + TDLib)

Неофициальный клиент Telegram для iPhone с функциями AyuGram (github.com/AyuGram, © Radolyn).

## Что перенесено из AyuGram Desktop
- Режим призрака: не отправлять прочтение, «в сети», «печатает…»; офлайн после отправки;
  чтение после действия; отложенная отправка (getScheduleTime); отправка без звука.
- Сохранение удалённых сообщений (отметка, полупрозрачность, отдельный список) и истории правок.
- Регулярные фильтры (инверсия, регистр, только каналы / все чаты), скрытие от заблокированных.
- Показ ID, секунды во времени, удаление «залго», режим стримера, свои метки.

## Сборка
iOS собирается только на macOS — это делает GitHub Actions (`.github/workflows/ios.yml`).
1. Запушить репозиторий на GitHub.
2. (Необязательно) добавить секреты `TG_API_ID` и `TG_API_HASH` с my.telegram.org —
   иначе приложение спросит их при первом запуске.
3. Скачать артефакт `AyuGram-ipa` и установить `AyuGram-unsigned.ipa` через Impactor.
